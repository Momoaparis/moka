# Moka

Moka est un chat dessiné à la main qui vit sur l'écran des salariés en télétravail : il compte le temps de travail,
pousse à faire des pauses et aide à déconnecter le soir.

Ce dépôt ne contient que les installateurs Windows de Moka (onglet **Releases**).
Moka est en cours d'essai et n'est pas encore diffusé.
